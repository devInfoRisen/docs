---

SMMPANEL AI needs access to your Perfect Panel so it can check orders and help with customer requests.

<Steps>
  <Step title="Open SMM Panel">
    In your system sidebar, click **SMM Panel**.
  </Step>

<Step title="Enter credentials">
  1. Base URL - your panel root, for example `https://panel.yourdomain.com` (no
  trailing slash). 2. Admin API key - from your Perfect Panel admin area.
</Step>

  <Step title="Save and test">
    Save, then run the connection test. Fix the URL or key if the test fails.
  </Step>
</Steps>

<Warning>
  Never share your Admin API key in chats or public repos. If it leaks, rotate
  it in Perfect Panel and update **SMM Panel** immediately.
</Warning>
