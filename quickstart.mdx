Follow these steps to go live with a basic setup.

<Steps>
  <Step title="Create your account">
    1. Open [https://smmpanel-ai.com](https://smmpanel-ai.com).
    2. Register and verify your email.
    3. Sign in to **My Systems**.
  </Step>

  <Step title="Launch a system">
    Start launch from **My Systems**, choose a name and plan, complete payment if asked, then click **Open Panel**.
  </Step>

  <Step title="Connect Perfect Panel">
    In the panel sidebar, open **SMM Panel**. Enter your panel base URL and Admin API key, then save and test the connection.

    <Warning>
      Use an Admin API key. Treat it like a password.
    </Warning>
  </Step>

  <Step title="Connect a channel">
    Open **Channels**. Add **WhatsApp** (scan QR) or **Telegram** (paste a bot token from BotFather). Wait until the channel shows as active.
  </Step>

  <Step title="Link a test customer">
    Open **Customers**, add your test chat identity, and save the matching Perfect Panel username.
  </Step>

  <Step title="Send a test message">
    From the linked number, try something like:

    ```text
    refill order 123
    ```

    Use a real order that belongs to that username. If ownership does not match, the bot will deny the request.
  </Step>
</Steps>
